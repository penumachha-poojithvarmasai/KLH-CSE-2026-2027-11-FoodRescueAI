# Unit Testing with JUnit 5 & Mockito

This directory contains standalone unit test documentation and references.

All active backend unit tests are colocated within their respective Maven modules following standard Spring Boot conventions:
- `backend/shipment-service/src/test/java/com/courierproof/shipmentservice/ShipmentServiceTest.java`

Run all unit tests using Maven:
```bash
cd backend
mvn test
```
